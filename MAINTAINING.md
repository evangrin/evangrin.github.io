# Updating this website

This is a plain HTML and CSS site for GitHub Pages. No package installation, build step, framework, or JavaScript is needed. The existing `README.md` is preserved as it was found.

- Edit `index.html` for the home page, `research.html` for projects, and `publications.html` for papers.
- All pages share `styles.css`. Keep the navigation consistent when adding a page.
- Replace paragraphs marked with the `editor-note` class as your final prose and links become available.
- To publish a CV, place a public-safe PDF named `cv.pdf` in this directory and link to it from `cv.html`.
- Commit and push changes to `main`; GitHub Pages serves the repository root.

The public site address is `https://evangrin.github.io/`.
